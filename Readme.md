# 🐍 Jeu Snake en TypeScript (version console)

Ce petit jeu **Snake** se joue dans le terminal en utilisant **Node.js**.  
Il est codé avec simplicité pour être compris même par des débutants.

## 🎮 Règles du jeu

- Le serpent se déplace dans une grille 10x10.
- Mange la nourriture (`@`) pour grandir.
- Ne touche pas les murs ni toi-même, sinon... 💀 **GAME OVER !**
- Ton score augmente à chaque nourriture mangée.

## ▶️ Comment lancer le jeu

Compile le fichier ts  : tsc snake.ts ensuite node snake.js

STD22019 et STD22017 binome
